# BrokenScript-Parser
A parser for a small func programming language, brokenScript, that aims to fix some slights I felt from other languages.

This is not meant to be a large, complete programming language.
Nor is is meant to be hyper optimized.
It is meant to be a fun experiment, and an exploration into making my own programming language.

I had fun making it, maybe you can have fun using it.
